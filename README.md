# 홀덤 테이블

노리밋 텍사스 홀덤 포커 웹앱. 설치 없이 브라우저에서 바로 플레이하고, 휴대폰 홈 화면에 앱처럼 추가할 수 있습니다.

## 플레이 방법

| 모드 | 방법 |
|---|---|
| 컴퓨터와 대결 | 상대 수(1~5명)와 난이도(이지·노멀·하드)를 고르고 ‘게임 시작’ |

### 컴퓨터 난이도

| 난이도 | 스타일 | 참여하는 판 | 특징 |
|---|---|---|---|
| 이지 | 초보 (루즈-패시브) | 약 60% | 웬만하면 따라옴, 레이즈·블러핑 거의 없음, 큰 베팅엔 포기 |
| 노멀 | 정석 (ABC) | 약 20% | 자리별 좋은 패만, 팟 오즈대로 콜·폴드, 블러핑 가끔 |
| 하드 | 프로 스타일 (TAG/LAG) | 약 27% | 포지션별 레인지, 상대 패 범위 읽기, 보드에 맞춘 베팅, 세미블러핑·리버 블러핑, 쇼다운으로 상대 블러핑 빈도 학습 |

- 어떤 난이도도 내 카드로 아무 족보가 없을 때 올인하지 않음 (시뮬레이션 수천 판에서 0회)
| 친구와 온라인 | ‘방 만들기’ → ‘초대 링크’를 친구에게 전송 → 친구가 링크를 열면 바로 자리에 앉음 (방장이 2~9명 중 선택, 게임 중에도 변경 가능) |
| 앱으로 설치 | 안드로이드 크롬: 메뉴 → ‘홈 화면에 추가’ / 아이폰 사파리: 공유 → ‘홈 화면에 추가’ |

## 규칙

- 시작 금액은 게임 전에 선택 (금액은 달러 표시)

| 시작 금액 | 블라인드 | 받는 칩 |
|---|---|---|
| $1,000 | $10/$20 | $100×4, $25×16, $5×40 |
| $10,000 | $50/$100 | $1,000×4, $500×6, $100×20, $25×40 |

- 칩 색: $1 흰색, $5 빨강, $25 초록, $100 검정, $500 보라, $1,000 노랑, $5,000 자주
- 헤즈업(2명) 블라인드 규칙, 최소 레이즈, 짧은 올인, 사이드 팟, 무승부 분배 적용
- 온라인은 한 차례 30초, 시간 초과 시 자동 체크(불가하면 폴드)
- 오른쪽 위 ♫ 버튼: 배경음악·효과음 켜기/끄기 (설정 기억)
- 판이 끝나면 폴드한 사람까지 전원의 카드를 공개하고, ‘이번 핸드 결과’ 표에서 카드·족보·승패를 비교

## 구조

- `index.html` 한 파일에 게임 엔진, 컴퓨터 AI, 화면이 모두 들어 있음
- 온라인 대전은 공개 MQTT 중계 서버(EMQX → HiveMQ → Mosquitto 순서로 자동 선택)를 거쳐 어떤 네트워크에서도 연결됨. 방장의 기기가 딜러 역할을 하며, 플레이어마다 따로 만든 키(ECDH P-256 + AES-GCM)로 암호화해서 중계 서버나 다른 사람은 카드·이름·채팅을 볼 수 없음
- 방장이 잠깐 다른 앱에 다녀와도 돌아오면 게임이 이어짐
- 방장이 게임 페이지를 완전히 닫으면 방이 끝남
- 화면: 휴대폰 세로는 가로로 긴 타원 테이블 위·아래로 자리 배치, PC·태블릿 가로(너비 1000px 이상)는 테이블 왼쪽·내 패와 채팅 오른쪽

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | 홈 화면 설치(PWA) |
| `src/ui.js` | 화면·온라인 코드 원본 (index.html에 합쳐져 있음) |
| `cards/*.webp` | J·Q·K 그림 카드 |
| `audio/lounge.mp3` | 배경음악 (이 앱용 창작곡, 80초 반복) |
| `tools/music-compose.js` | 배경음악 작곡·합성 코드 |

## 그림 출처

- J·Q·K 그림: [Vector Playing Cards](https://github.com/notpeter/vector-playing-cards) (원작자 Byron Knoll, 퍼블릭 도메인). 웹용으로 크기를 줄여 WebP로 변환함
- 숫자 카드 문양과 스페이드 A 장식은 이 앱에서 직접 그림
- 배경음악과 효과음은 외부 음원 없이 코드로 직접 작곡·합성함 (저작권 문제 없음)
