# 홀덤 테이블

노리밋 텍사스 홀덤 포커 웹앱. 설치 없이 브라우저에서 바로 플레이하고, 휴대폰 홈 화면에 앱처럼 추가할 수 있습니다.

## 플레이 방법

| 모드 | 방법 |
|---|---|
| 컴퓨터와 대결 | 상대 수(1~5명)와 난이도(이지·보통·하드)를 고르고 ‘게임 시작’ |
| 친구와 온라인 | ‘방 만들기’ → ‘초대 링크’를 친구에게 전송 → 친구가 링크를 열면 바로 자리에 앉음 (방장이 2~9명 중 선택, 게임 중에도 변경 가능) |
| 앱으로 설치 | 안드로이드 크롬: 메뉴 → ‘홈 화면에 추가’ / 아이폰 사파리: 공유 → ‘홈 화면에 추가’ |

## 규칙

- 시작 칩은 게임 전에 선택: 1,000개(블라인드 10/20) 또는 10,000개(블라인드 50/100)
- 헤즈업(2명) 블라인드 규칙, 최소 레이즈, 짧은 올인, 사이드 팟, 무승부 분배 적용
- 온라인은 한 차례 30초, 시간 초과 시 자동 체크(불가하면 폴드)

## 구조

- `index.html` 한 파일에 게임 엔진, 컴퓨터 AI, 화면이 모두 들어 있음
- 온라인 대전은 공개 MQTT 중계 서버(EMQX → HiveMQ → Mosquitto 순서로 자동 선택)를 거쳐 어떤 네트워크에서도 연결됨. 방장의 기기가 딜러 역할을 하며, 플레이어마다 따로 만든 키(ECDH P-256 + AES-GCM)로 암호화해서 중계 서버나 다른 사람은 카드·이름·채팅을 볼 수 없음
- 방장이 잠깐 다른 앱에 다녀와도 돌아오면 게임이 이어짐
- 방장이 게임 페이지를 완전히 닫으면 방이 끝남
- 일부 회사·학교 와이파이나 통신망에서는 브라우저 간 직접 연결이 막힐 수 있음

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | 홈 화면 설치(PWA) |
| `src/ui.js` | 화면·온라인 코드 원본 (index.html에 합쳐져 있음) |
